# PA Agent Bug Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复已确认的高风险运行时问题，并逐步清理探测线程、数据源请求和测试回归问题。

**Architecture:** 先处理配置加载和 Qt 线程生命周期，再修正 TradingView/数据源探测的超时语义，最后优化行情请求和静态检查。每项修复都保持现有接口不变，优先通过请求本身的超时和显式线程退出保证资源可回收。

**Tech Stack:** Python 3.14, PyQt6, concurrent.futures, Pydantic v2, pytest, ruff。
