# 决策栏布局整合设计

## 目标

将“未来走势预期”并入“决策”栏底部，统一展示交易决策与未来走势信息；当内容超过可视高度时，让整个决策栏上下滚动。标签顺序调整为“实时”之后紧接“决策”，再到“决策树”。

## 已确认的界面方案

采用推荐方案一：单一滚动栏。

- 保留“分析设置”作为侧栏第一个工具页。
- 标签顺序为：分析设置、实时、决策、决策树、决策树可视化、原始、调试。
- 移除独立的“未来走势预期”标签；未来走势内容作为决策页底部的普通区块。
- 决策页使用一个外层垂直滚动容器，滚动时覆盖决策页全部内容，而不是给某个局部小框单独滚动。
- “分析理由”“置信度理由”“风险评估与失效条件”改为始终展开的标题加文本区域，不再使用可折叠小框。
- 未来走势区保留“下一根 K 线预期”和“下一个市场周期预期”两部分，放在决策内容最底部；其内部预测理由也始终展开。

## 组件与数据流

`AISidebar` 继续持有一个 `DecisionPanel` 实例，并把它放入 `QScrollArea`。`DecisionPanel` 内部新增/挂载未来走势内容区，继续通过现有 `set_prediction()` 数据接口更新预测。主窗口分析完成和演示回放完成时，只需把同一份 `inner` 决策数据传给决策面板；清理和主题刷新也由决策面板统一负责。删除独立未来走势页及其主窗口引用，避免同一预测数据出现两个入口。

## 兼容性与边界

- 决策数据缺少预测字段时，底部未来走势区保持隐藏，不显示空白占位。
- 现有决策结论、市场诊断、置信度、交易参数、理由和风险字段保持原有内容与计算逻辑。
- 不改变决策树、决策树可视化、实时流和原始调试页的内容及交互。
- 不改变数据模型、提示词或 AI 输出契约。

## 验证标准

1. 侧栏标签文本和常量索引符合新顺序，启动页仍为“实时”。
2. 决策页内容超出窗口高度时出现一个整页垂直滚动条，决策内容区没有折叠按钮。
3. `next_bar_prediction` 与 `next_cycle_prediction` 均显示在决策页底部；缺少字段时安全隐藏。
4. 分析完成、演示回放、清理和主题切换路径均能更新/清空合并后的决策页。
5. 相关单元测试通过，并完成一次 offscreen GUI 构造验证。
