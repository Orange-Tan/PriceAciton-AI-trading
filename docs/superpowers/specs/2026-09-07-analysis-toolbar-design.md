# 分析顶部栏复刻设计

## 目标

将右侧「分析设置」中的行情与分析操作迁移到工作台顶部，复刻参考图的单行横向工具栏。顶部栏只显示可操作项和行情状态，不显示等待 K 线收盘、倒计时或 AI 分析阶段状态；AI 分析状态统一在右侧「实时」页显示。

## 顶部栏结构

控件从左到右固定为：

1. 「数据源」标签与数据源下拉框。
2. 「交易所」标签与交易所下拉框。
3. 「品种」标签与自动品种显示框。
4. 「代码/名称」标签、可编辑代码框和搜索入口。
5. 「周期」标签与周期下拉框。
6. 「获取数据」按钮。
7. 「提交分析」按钮；现有增量分析可用时继续只改变该按钮文字。
8. 「持续跟踪」标签与开关。
9. 分隔线。
10. 「图表实时更新」文字与实时状态指示点。
11. 设置按钮。

顶部栏始终保持一行。窗口宽度不足时，外层提供横向滚动能力，控件不换行、不裁掉，也不改变业务顺序。

## 品种显示

品种控件保持参考图中的下拉框外观，但不可手动修改。只消费当前数据源明确提供的品种字段，并在切换数据源或成功加载新 K 线时同步更新；不根据代码、交易所或字符串规则自行推断。

数据源未提供品种字段时隐藏该控件及其标签，不显示「其他」等猜测值，也不阻断获取数据或提交分析。

## 状态与交互

- 删除右侧栏中的「分析设置」Tab，右侧栏启动时仍选中「实时」。
- 删除旧的分析状态条及其顶部决策徽标、模型说明展示。
- 不在顶部栏显示「等待最新 K 线收盘后再提交分析」复选框、等待文字或倒计时。
- 提交分析直接沿用当前立即提交路径，不再进入等待收盘交互。
- 准备、分析、重试、错误和完成等 AI 状态仅写入「实时」页首行；底部状态栏只保留数据连接、订阅和普通操作提示。
- 「图表实时更新」状态只表达图表刷新是否运行：运行显示绿色实心点，暂停显示中性或警示色点。
- 设置按钮复用现有设置对话框入口，不新增第二套设置逻辑。
- 现有数据源、交易所、代码、周期、获取数据、提交/增量分析、持续跟踪和图表恢复逻辑保持不变；参考图未包含的图表适配按钮不进入顶部栏。

## 组件边界

- `MainWindow` 负责创建顶部栏、复用现有控件和连接现有信号。
- `AISidebar` 只保留实时、决策、决策树、决策树可视化、原始和调试页，并相应更新 Tab 常量。
- 品种显示只读取数据源元数据，不新增本地品种推断函数。
- `AIStreamPanel` 继续作为分析状态的唯一可见承载区，不改变流式内容与追问行为。

## 错误与降级

- 品种推断失败时显示「其他」，不弹窗。
- 无 API Key 的提示不占用顶部栏；继续通过现有状态/设置入口引导用户。
- 交易所不适用时沿用现有可见性规则，不为保持占位而伪造可选值。

## 验收与测试

1. 顶部栏的可见控件、顺序和单行关系与参考图一致。
2. 右侧栏不存在「分析设置」Tab，「实时」成为第一个且默认选中的 Tab。
3. 等待收盘复选框和倒计时不再出现在界面中，提交分析不会进入等待状态。
4. 分析状态只出现在「实时」页，不在顶部栏或旧状态条重复显示。
5. 数据源提供品种字段时正确显示；未提供时品种控件及标签隐藏，代码/交易所不会触发本地猜测。
6. 图表实时更新指示点随暂停/恢复状态变化。
7. 设置按钮仍能打开现有设置对话框。
8. 相关 PyQt 单元测试在 `QT_QPA_PLATFORM=offscreen` 下通过。
