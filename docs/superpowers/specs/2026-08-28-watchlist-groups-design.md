# 自选股板块与行情摘要设计

## 目标

将现有左侧单一自选股列表升级为“板块栏 + 股票表格”布局，方便在多个自选板块之间切换，并为后续批量 AI 扫描预留入口。当前迭代只实现板块管理、行情摘要展示和批量扫描确认提示，不执行批量 AI 分析。

## 交互布局

左侧自选区域由两列组成：

```text
┌──────────┬──────────────────────────────────────┐
│ 自选板块  │ 自选股                               │
│          │ 代码   名称   现价   今日涨幅  今日决策 │
│ 全部     │ 600519 贵州茅台 1488  +1.25%   买入    │
│ 核心持仓 │ 000001 平安银行 11.42 -0.63%   卖出    │
│ 观察列表 │                                      │
│ ＋新增板块│                                      │
└──────────┴──────────────────────────────────────┘
```

顶部操作区包含：`＋ 新增板块`、`＋ 添加自选股`、`分析当前板块`。点击板块名称后，右侧表格仅显示该板块中的股票。板块列保持窄宽，股票表格占主要空间。

## 股票字段与样式

每行显示：

- 代码：规范化后的股票代码。
- 名称：本地代码名称映射；未知代码回退显示代码。
- 现价：当前行情源的最新价。
- 今日涨幅：当前交易日涨跌幅。
- 今日决策：默认空值，不显示“未分析”。

决策颜色规则：

- 当日买入：红色。
- 当日卖出：绿色。
- 非当日决策、观望或无决策：深灰色。

“当日”按本地自然日判断，历史决策不得误显示为当日信号。

## 数据模型与兼容

现有 `GeneralSettings.watchlist: list[str]` 扩展为板块结构，建议字段形态：

```python
watchlist_groups = {
    "全部": ["600519", "000001"],
    "核心持仓": ["600519"],
    "观察列表": ["000001"],
}
```

旧版 `watchlist` 配置迁移到“全部”板块，不能丢失已有代码。板块新增、重命名、删除和股票归属变化都要持久化；“全部”板块不允许删除。

行情更新沿用现有数据源和刷新循环。名称映射作为独立 helper，未知代码安全回退。决策数据以股票代码为键，保存决策文本和产生日期；本迭代只负责渲染已有数据，不新增批量分析任务。

## 批量扫描入口（仅确认，不执行）

点击“分析当前板块”时计算当前板块股票数量并弹出确认：

- 0 只：提示当前板块为空，不执行。
- 1–5 只：显示数量并允许确认；确认后调用预留接口（当前返回未实现提示）。
- 超过 5 只：额外提示“将消耗较多 token”，用户明确确认后才进入预留接口。
- 取消始终不改变任何数据。

本轮不启动逐只 AI 请求、不改变当前分析任务、不并发创建后台扫描 worker。

## 组件边界

- `WatchlistPanel`：板块列表、股票表格、顶部操作、选择/增删信号。
- `WatchlistStore` 或设置适配层：板块结构校验、旧配置迁移、持久化。
- 行情适配 helper：把当前数据源快照转换为名称、现价、涨幅字段。
- 决策展示 helper：按日期和买卖方向返回文本与颜色。
- `MainWindow`：连接板块选择、股票点击切图、刷新数据和确认提示；不承载表格细节。

## 错误处理

- 配置损坏或字段类型不符时回退到“全部”空板块，并保留可恢复的旧列表。
- 行情暂不可用时现价和涨幅显示空值，不阻塞板块切换。
- 名称映射缺失时显示代码。
- 删除板块前要求确认；删除板块中的股票只影响归属，不删除其他板块中的同一代码。

## 测试

新增单元测试覆盖：

1. 板块新增、切换、重命名、删除和“全部”保护。
2. 股票添加到指定板块、去重、删除与旧 `watchlist` 迁移。
3. 代码、名称、现价、涨幅和空值显示。
4. 当日买入红色、当日卖出绿色、历史决策深灰色。
5. 分析数量提示、超过 5 只的二次确认和取消路径。

## 非本轮范围

- 批量 AI 分析执行、并发调度、进度队列和结果落盘。
- 自动获取完整市场名称数据库。
- 跨设备同步板块配置。
