# 默认窗口尺寸设计

## 目标

让 PA Agent 在不同 Mac 屏幕和外接显示器上启动时自动适配，默认窗口使用当前主屏幕可用区域的 90% 宽度和 90% 高度。

## 行为

- 从 `QGuiApplication.primaryScreen()` 获取主屏幕。
- 使用 `availableGeometry()`，避免覆盖 macOS 菜单栏、Dock 等系统区域。
- 默认尺寸为可用宽高分别乘以 `0.90` 后取整。
- 屏幕信息不可用时，使用现有的固定后备尺寸 `1280×820`。
- 不改变窗口布局、最小尺寸、用户手动调整行为或持久化设置。

## 实现范围

仅调整 `pa_agent/gui/main_window.py` 中 `MainWindow.__init__` 的默认尺寸计算；补充针对尺寸计算边界的单元测试（如现有测试基础设施允许），并运行相关测试与静态检查。
