# 分析完成提示静默设计

## 目标

分析流程结束后，无论成功还是结束时存在错误，都不再弹出或推送“分析完成/分析结束”类提示。分析结果、错误状态和现有的状态栏信息继续保留，便于用户在界面中查看；其它与配置、数据源或用户主动操作相关的错误提示不受影响。

## 现状与范围

- `pa_agent/gui/main_window.py` 的 `MainWindow._on_worker_done` 负责分析工作线程收尾，并在成功或错误结束时写入状态栏。
- 仓库中的 `ToastOverlay` 组件提供“分析完成”轻提示，但本次不改变其通用能力；仅确保分析收尾路径不触发完成提示。
- 本次不新增设置项、不改变分析编排、不删除状态栏状态文本，也不修改配置/数据源等其它弹框。

## 方案

在分析工作线程收尾路径中移除完成提示触发逻辑（若当前实现通过状态栏承载完成状态，则保留该状态栏更新，不把它视为弹框）。成功和“存在错误”的结束分支统一不发出完成类弹框。通过单元测试验证两种结束状态均不会调用完成提示入口，同时保留收尾状态更新行为。

## 测试与验收

1. 新增回归测试覆盖成功结束和带错误结束两条分支，断言完成提示入口未被调用。
2. 运行新增测试及相关 GUI 单元测试。
3. 验收标准：分析结束不出现任何完成类弹框/Toast；分析状态栏仍按现有逻辑更新；其它既有提示行为不变。
